راهنمای راه‌اندازی از صفر: SAM AI (گفت‌وگو + جست‌وجوی وب + ساخت تصویر)
=====================================================================

اول بدان:
- Worker قبلی حذف شده، پس باید از صفر در حساب کلودفلر ساخته شود. دستور wrangler deploy این کار را خودش می‌کند.
- گفت‌وگو و ساخت تصویر با Workers AI کلودفلر کار می‌کنند و کلید جداگانه نمی‌خواهند.
- جست‌وجوی وب با LangSearch (langsearch.com) کار می‌کند و به یک کلید نیاز دارد.
- اگر سایتی باز نشد، همان را به من بگو تا راه دیگری پیدا کنیم.

بخش ۱: کلید LangSearch
1) سایت سایت LangSearch را باز کن و ثبت‌نام کن (یا وارد شو).
2) در داشبورد، کلید API خودت را کپی کن.

بخش ۲: حساب کلودفلر
1) سایت dash.cloudflare.com را باز کن و ثبت‌نام کن یا وارد شو.
2) در نوار جست‌وجوی بالای داشبورد «Workers AI» را بنویس و صفحه‌اش را باز کن. اگر پیامی برای فعال‌سازی دیدی، آن را تأیید کن.

بخش ۳: ترمینال VS Code
(اگر Node.js نداری، از nodejs.org نسخهٔ LTS را نصب کن؛ بعد VS Code را ببند و دوباره باز کن.)
1) VS Code را باز کن؛ از منوی File گزینهٔ Open Folder را بزن و پوشهٔ Sam_math را انتخاب کن.
2) از منوی Terminal گزینهٔ New Terminal را بزن.
3) بنویس:  node -v   و Enter بزن. اگر شماره نسخه نشان داد، ادامه بده.
4) وارد پوشهٔ Worker شو:
   cd cloudflare-sam-ai
5) وارد حساب کلودفلر شو:
   npx wrangler login
   مرورگر باز می‌شود؛ گزینهٔ Allow را بزن و به ترمینال برگرد.
6) کلید LangSearch را امن ذخیره کن:
   npx wrangler secret put LANGSEARCH_API_KEY
   Enter بزن؛ وقتی مقدار را خواست، کلیدی را که کپی کرده‌ای Paste کن و Enter بزن.
   (اگر PowerShell ویندوز خطای «running scripts is disabled» داد، به‌جای npx بنویس npx.cmd)
7) Worker را از صفر منتشر کن:
   npx wrangler deploy
   در پایان آدرسی مثل https://sam-ai-backend.xxxx.workers.dev چاپ می‌شود. آن را کپی کن.

بخش ۴: گذاشتن آدرس در سایت
1) در VS Code کلید Ctrl+H را بزن (Find and Replace).
2) در کادر اول بنویس:  PASTE_YOUR_WORKER_URL_HERE
3) در کادر دوم آدرسی را بنویس که در مرحلهٔ 7 کپی کردی (فقط متن داخل گیومه‌ها عوض می‌شود).
4) دکمهٔ Replace All را بزن. این کار در sam-ai.js و sam-voice.js و sketch.js و exam.js هر چهار را درست می‌کند.

بخش ۵: تست
1) فایل index.html را با Live Server یا دوبار کلیک باز کن و به بخش SAM AI برو.
2) یک سؤال عادی بپرس؛ باید جواب بدهد و خودش را «SAM AI» معرفی کند.
3) تیک «🌐 جست‌وجو در وب» را بزن و سؤال خبری بپرس؛ زیر جواب لینک منابع باید ظاهر شود.
4) متنی بنویس و روی «🖼 ساخت تصویر» بزن؛ چند ثانیه بعد تصویر نمایش داده می‌شود.
5) برای دستیار صوتی، در صفحهٔ اصلی دکمهٔ «دستیار صوتی» پایین‌چپ را روشن کن و بگو «برو به هندسه».

اگر خطا دیدی:
- «کلید جست‌وجوی وب تنظیم نشده»: مرحلهٔ 6 را انجام بده و بعد npx wrangler deploy را بزن.
- خطای مربوط به ai یا binding: Workers AI در داشبورد کلودفلر فعال نیست؛ بخش ۲ را انجام بده.
- «آدرس SAM AI هنوز تنظیم نشده»: بخش ۴ را انجام بده.
- خطای HTTP 401 یا 403 از جست‌وجو: کلید LangSearch را دوباره بساز و مرحلهٔ 6 را تکرار کن.

نکته: اگر نسخهٔ EXE ویندوزی می‌سازی، بعد از این تغییرات دوباره npm run build:portable را اجرا کن.
