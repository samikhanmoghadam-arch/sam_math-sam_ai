SAM MATH / SAM AI — تغییرات ۵ نوامبر ۲۰۲۶
=============================================

تغییرات این بسته
- بخش «ارتباط با ما» و همهٔ فرم‌ها/منوهای مربوط به آن حذف شده است.
- شمارهٔ موبایل از فرم ورود حذف شده است.
- ورود دیگر اجباری نیست؛ سایت بدون حساب باز می‌شود و حساب پیش‌فرض «Sam» نیز پاک می‌شود. دکمهٔ «ورود» برای ساخت پروفایل اختیاری باقی مانده است.
- بخش چالش ذهنی به آرکید ۲۰ حالته تبدیل شده است: جمع، تفریق، ضرب، تقسیم، درصد، مربع، جذر، توان، عدد گمشده، مقایسه، دنباله، زوج/فرد، عدد اول، کسر، ب.م.م، ک.م.م، دوبرابر، سه‌برابر، محاسبهٔ ذهنی و عملیات معکوس؛ به‌علاوهٔ حالت ترکیبی.
- امتیازدهی سخت‌تر شده و زنجیرهٔ جواب درست و سطح بازی روی امتیاز اثر دارند. مجموع امتیاز و رکورد در «پیشرفت من» ثبت می‌شود.
- سهمیهٔ ساخت تصویر در Worker: بدون ایمیل ۱ تصویر روزانه برای شناسهٔ دستگاه؛ با ایمیل ۱۰ تصویر روزانه برای همان رشتهٔ ایمیل.
- جست‌وجوی وب فعلی با Serper پیاده شده و Worker کلید را از Secret با نام SERPER_API_KEY می‌خواند.

نکتهٔ مهم دربارهٔ حساب ایمیل
در این نسخه، ایمیل تأیید نمی‌شود؛ واردکردن یک ایمیل به‌تنهایی احراز هویت واقعی نیست و هرکس می‌تواند ایمیل دیگری را وارد کند. برای سهمیهٔ واقعاً امن و اتصال پیشرفت بین دستگاه‌ها باید ورود با کد یک‌بارمصرف و پایگاه‌دادهٔ کاربران اضافه شود.

راه‌اندازی Worker در VS Code (Windows PowerShell)
1) VS Code را باز کن و پوشهٔ Sam_math را باز کن. Terminal > New Terminal را بزن.
2) دستورهای زیر را اجرا کن:

   cd .\cloudflare-sam-ai
   node -v
   npx.cmd wrangler login

3) کلید API جدید Serper را به‌صورت Secret ثبت کن (کلید را داخل فایل JS یا GitHub نگذار):

   npx.cmd wrangler secret put SERPER_API_KEY

   وقتی پیام Enter a secret value آمد، کلید جدید را Paste کن و Enter بزن.

4) سهمیه فقط با KV واقعاً اعمال می‌شود. یک‌بار این دستور را اجرا کن:

   npx.cmd wrangler kv namespace create SAM_LIMITS

   خروجی یک شناسهٔ id می‌دهد. فایل cloudflare-sam-ai/wrangler.jsonc را باز کن و قبل از بستهٔ پایانی } این بخش را اضافه کن؛ مقدار id را با شناسهٔ واقعی جایگزین کن:

   ,"kv_namespaces": [
     { "binding": "SAM_LIMITS", "id": "شناسه-واقعی-KV" }
   ]

   دقت کن اگر در فایل بعد از ai یک ویرگول گذاشتی، JSONC معتبر بماند. نمونهٔ نهایی:
   {
     "$schema": "node_modules/wrangler/config-schema.json",
     "name": "sam-ai-backend",
     "main": "src/index.js",
     "compatibility_date": "2026-10-20",
     "ai": { "binding": "AI" },
     "kv_namespaces": [
       { "binding": "SAM_LIMITS", "id": "شناسه-واقعی-KV" }
     ]
   }

5) حالا Worker را منتشر کن:

   npx.cmd wrangler deploy

   آدرس Worker باید با آدرسی که در sam-ai.js و sam-voice.js تنظیم شده یکی باشد. آدرس فعلی پروژه در sam-ai.js این است:
   https://sam-ai-backend.sami-math-lab.workers.dev

6) برای انتشار سایت از طریق GitHub متصل به Cloudflare Pages، از ریشهٔ پوشهٔ Sam_math اجرا کن:

   git status
   git add .
   git commit -m "Upgrade SAM MATH arcade and remove contact"
   git push

   اگر پروژه به GitHub متصل باشد، Cloudflare Pages پس از Push به‌صورت خودکار Build/Deploy می‌کند.

تست پس از انتشار
- صفحهٔ اصلی باید بدون پنجرهٔ ورود و بدون حساب پیش‌فرض باز شود.
- در منو نباید «ارتباط با ما» باشد.
- در چالش ذهنی باید ۲۰ حالت و حالت ترکیبی دیده شود. یک بازی را تا پایان ۶۰ ثانیه انجام بده؛ تعداد بازی‌ها، مجموع امتیاز و رکورد در پیشرفت من ثبت می‌شوند.
- در SAM AI تیک جست‌وجوی وب را روشن کن و یک پرسش روز/موضوع تازه بپرس؛ پاسخ باید همراه منابع باشد.
- سهمیهٔ تصویر فقط پس از اتصال KV اعمال می‌شود. یک تصویر مهمان بساز؛ تصویر دوم همان روز باید رد شود. با ایمیل، سقف روزانه ۱۰ است.

عیب‌یابی جست‌وجو
- خطای «کلید تنظیم نشده» یعنی Secret ثبت نشده یا Worker پس از ثبت Secret دوباره Deploy نشده است.
- HTTP 401/403 معمولاً به کلید نامعتبر یا دسترسی/اعتبار Serper مربوط است؛ کلید تازه را با همان دستور Secret ثبت و Deploy کن.
- اگر API جدیدت Serper نیست، فقط کلید کافی نیست؛ آدرس endpoint و ساختار درخواست/پاسخ آن سرویس نیز باید در webSearch داخل src/index.js با مستندات همان API هماهنگ شود.

این بسته Worker را از حساب Cloudflare تو منتشر نمی‌کند؛ اجرای دستورهای بالا با حساب خودت لازم است.
